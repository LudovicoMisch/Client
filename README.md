# 💬 Client Chat WebSocket

Un semplice **client chat** realizzato in **HTML, CSS e JavaScript** che utilizza una connessione **WebSocket** per comunicare con un server in tempo reale.  
Permette di effettuare il login, inviare e ricevere messaggi, e gestire la connessione in modo semplice e intuitivo.

---

## 🚀 Funzionalità principali

- ✅ Login con nome utente e password  
- 💬 Invio e ricezione di messaggi in tempo reale  
- 🕓 Visualizzazione della data e ora di ogni messaggio  
- 🔒 Logout e chiusura connessione con un clic
